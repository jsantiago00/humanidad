# Crónica de una civilización

Simulador de civilización emergente que corre en el navegador. Agentes humanos con sus propias estadísticas sobreviven, se reproducen y desarrollan tecnología, y la historia de la civilización se va escribiendo sola.

## ▶️ Jugar

**https://jsantiago00.github.io/humanidad/**

## Cómo correrlo localmente

Es un único archivo HTML sin dependencias: descargá `index.html` y abrilo en cualquier navegador.

## Hecho con

HTML, CSS y JavaScript puro, en un solo archivo.
